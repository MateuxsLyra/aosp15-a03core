# AOSP para Samsung Galaxy A03 Core

Projeto comunitário de desenvolvimento de ROM baseada em AOSP
para Samsung Galaxy A03 Core SM-A032M.

## Objetivos

- Desenvolver uma ROM com código-fonte documentado.
- Investigar a compatibilidade com o firmware Unisoc SC9863A.
- Distribuir os pacotes de instalação através do Odin3/Odin4.
- Documentar builds, hashes e problemas conhecidos.

## Estado atual

Fase: auditoria do dispositivo e preparação da árvore de código.

Ainda não existe uma build AOSP própria neste repositório.

O diretório de análises local fica separado deste projeto.
